# Loan Approval Prediction System
**Course:** BCA (AI & Data Science) | **University:** CT University

## Project Overview
This project uses Machine Learning to predict whether a loan application will be approved based on applicant details such as Income, Credit History, Education, and Marital Status.

## Tech Stack
* **Language:** Python
* **Environment:** Google Colab
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Model:** Random Forest Classifier

## How to Run
1. Open the `.ipynb` file in Google Colab.
2. Upload the `train` and `test` CSV files provided in this repository to the Colab sidebar.
3. Run all cells to see the EDA and Model Predictions.

## Results
The model achieved an accuracy of approximately 76% on the validation set. Credit History was found to be the most critical factor for loan approval.
